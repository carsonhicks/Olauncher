# CLauncher

This is a personal fork of [Olauncher](https://github.com/tanujnotes/Olauncher), a minimal Android launcher. I maintain it for my own day-to-day use and have made changes here that aren't part of the upstream project, so expect it to drift from the original over time.

If you're looking for the actively maintained, original project, go to [tanujnotes/Olauncher](https://github.com/tanujnotes/Olauncher) instead.

## Weather

Weather data is provided by [Open-Meteo](https://open-meteo.com/), a free, open-source weather API.
